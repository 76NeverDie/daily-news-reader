开启「点击即抓取」

本页是纯静态网页，新闻抓取由 GitHub Actions 在云端完成。点一下「抓取」，页面会触发一次真实抓取任务，数据写回仓库后自动刷新，手机和电脑都能看到。

需要你自己的 GitHub 令牌来发起这一次触发。推荐 创建细粒度令牌 ↗：仓库只选 daily-news-reader，权限只勾 Actions: Read and Write；也可用 classic 令牌（勾 repo）。

令牌只保存在本机浏览器的 localStorage，不会上传、不会写入网站代码，可随时清除。公开页面请勿把令牌写进仓库。手机与电脑需各自配置一次。
